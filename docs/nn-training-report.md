# NN学習基盤・試運転結果

この文書は旧報酬（行動±1・勝敗±5）での記録です。その後の新報酬（ハート箱の点数÷2・勝敗±7）の結果は [nn-reward-comparison.md](nn-reward-comparison.md) を参照してください。

実施日：2026-10-29。今回は学習基盤の実装と短い試運転まで。10,000試合の本学習・公開モデルの採用・ゲーム画面へのNN追加はまだ行っていません。

## 実装済み

- 203特徴量、64×2層tanh、25行動logitと価値出力。
- 公開履歴のみの入力、役割・残存箱による合法手マスク。
- 指定された各行動±1/0、勝敗±5/0の報酬。最後の行動には両方を加算。
- 既存JavaScriptルールを使う常駐学習環境、Python/PyTorchのPPO。
- 保存した過去NNとの対戦、固定相手の評価、JSONモデルのJavaScript推論。
- 重み、最適化器、乱数、相手配分、試合ログを含む保存・再開。
- 10,000試合の配分・停止設定と、学習とは別の評価設定。

## 検証結果

| 検証 | 結果 |
| --- | --- |
| JavaScript自動テスト | 25件成功。既存の5,000ランダム試合・4種CPUの320試合を含む |
| Python自動テスト | 4件成功 |
| Python/JS推論一致 | 行動確率の最大絶対差5.96×10^-8（基準1×10^-5以内） |
| 重み更新 | 初期JSONと128試合後のJSONが異なることを確認 |
| 損失・勾配 | 有限値を確認し、異常時停止のチェックを実装 |
| 保存再開 | 28試合で停止→128試合まで再開と、128試合の連続実行が完全一致 |

保存再開の比較対象は最終重み、全試合ログ、各更新の損失・指標、評価結果、Python/Torch乱数状態。CPUのみ・同一環境・同一seedの検証です。異なる乱数seedでの学習結果の再現性を示すものではありません。

## 試運転の件数

1系列は128学習試合、2,256判断、20回のPPO更新バッチ。①②④⑤を各26試合、③過去NNを24試合。最初の8試合後の保存モデルから③を有効にしました。

再開検証のため同じ系列を2回実行したので、試運転として実際に処理した学習試合は計256試合です。各系列の学習前80・学習後100の評価を合わせ、評価は計360試合。Pythonユニットテスト内の16評価試合と推論一致確認用の2試合も別途実行しました。これらを本学習10,000試合には含めません。

連続実行の学習開始から最終評価・保存までは30.44秒でした。初期評価、Python/PyTorchの起動・読み込み時間を含みません。再開検証と同時実行した際の参考実測であり、本学習の所要時間を保証しません。
